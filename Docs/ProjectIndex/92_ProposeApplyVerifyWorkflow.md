## Main-window operation

**Propose** commits valid pending numeric editors, uses the session's existing
method and preferences, and preserves actual applied processing. Missing Source
or Current measurements are visible preparation phases. First-import identical
Source-to-Current initialization retains its measured origin. Current manual
gains and transitions are never reset to Original for proposal preparation.

The existing generator runs unchanged. An exact, complete measured pass is
selected through the service's existing validity rules, applied while stopped,
then independently measured in the Current domain. Candidate PASS cannot supply
Current PASS. Forecast-only Standard global corrections receive one private
measurement of their exact unchanged plan before Apply; existing measured ready
results do not acquire that extra pass. Already-passing Current needs no change.

The main panel and top feedback show preparing, finding, applying, verifying and
the final result. A verified numerical pass with advisory boundary uncertainty
keeps **Measured requirements passed — check region boundaries** visible. The
message identifies uncertain intervals, and **Inspect region boundaries** opens
the applied Current handles. Every region remains reachable through the gain
lane and every explanation through optional review. Listening review remains
separate from numerical verification; finalized export is still independently
verified.

Eligible measured alternatives appear in the main panel. The initial choice uses
the existing recommended/retained ordering, with no acoustic-quality ranking.
Switching installs the alternative's absolute plan from the same captured
pre-Propose baseline, then independently remeasures Current. Pending selection
does not change the displayed applied choice until the transaction succeeds.
Browsing an attempt in detailed inspection does not select or apply it.

**Restore before Propose** restores original processing, explanation and gain
provenance. Each successful Apply, alternative switch and recovery is an Undo
operation. Undo/Redo restore processing and documentary history, never old
measurement or proposal authority. Cancel/failure before Apply keeps Current
unchanged. Cancel/failure during post-Apply verification keeps the applied plan
unverified and offers independent remeasurement or recovery. A completed measured
FAIL remains an honestly verified FAIL.

No eligible pass preserves processing and reports the existing measured failure,
unsupported requirement or finite search/preference limit. It makes no general
impossibility claim. New/Open, playback, competing processing edits and Save wait
while the operation is active. It never starts playback or changes routing.

## Ownership, persistence and service changes

The bounded runtime operation captures the original request, result, processing
and provenance. Every asynchronous completion checks runtime, operation
generation, expected phase, revision and current inputs before publishing either
success or failure. Finished worker controls are released before the next stage.
Manual edits and incompatible settings changes revoke replacement authority;
restoring equal settings cannot revive it. A transient boundary preview suspends
choices, and Escape can retain authority when nothing was committed.

At commit the selected object must belong to the exact captured result, pass
full-precision measurement and planning constraints, and match the live expected
processing, runtime, revision, source/roles/range, requirements and preferences.
The transaction prepares bounded history and writes recoverable Undo data before
processing mutation. It does not restore an old whole session or rewind revision.

Schema-1 comparisons retain compact worker-minted measurement receipts rather
than one full window population per alternative. Each generation and selectable
attempt has its own identity, even when two runs produce identical audio plans.
The selected receipt supplies the matching plan, measured evidence and history.
The anchored failure shortlist may select a previously non-winning attempt; an
unrelated full snapshot is never exposed as that attempt's evidence. Existing
three-measurement/64-proxy/64 MiB planning bounds and early exit when comparison
is disabled remain in force. Receipt storage accounts for owned processing
intervals and input contexts, including separate-file/composed sources.

Standard scalar proposals preserve applied provenance; Standard section
proposals preserve the editorial map required by their existing next-generation
path. LRA/region proposals retain interval-derived provenance. No proposal
mathematics, search strategy, dispatch, gain policy, default margins or processing
engine changes. Saved explanations remain documentary; reopening cannot restore
runtime alternative-selection authority. Existing prospective session formats
remain in use.
